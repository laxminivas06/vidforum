# AI-Native SDLC Skill

Bakes human approval gates directly into the development process.

## Gates
- **Gate 1:** PRD + Tech Spec + Tasks approval (Phase 0).
- **Gate 2:** Scaffold verification in-browser.
- **Gate 3:** Feature group demonstration & test verification.
