# PR Storyteller Skill

Drafts descriptive pull request documentation.

## Structure
1. **Title:** Semantic and concise.
2. **Summary:** Problem solved and approach taken.
3. **Changes:** Bulleted breakdown by module.
4. **Test Plan:** Exact steps and commands to reproduce verification.
