# MegaLinter Skill

Orchestrates linting and formatting across project technologies.

## Target Toolchains
- **Python:** `ruff check`, `ruff format`, `mypy`.
- **TypeScript / React:** `tsc --noEmit`, `eslint`, `prettier`.
- **CSS / Tailwind:** PostCSS and responsive class validation.
