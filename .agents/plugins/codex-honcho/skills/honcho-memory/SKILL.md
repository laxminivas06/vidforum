# Honcho Memory Skill

Provides persistent cross-session memory by capturing and recalling durable insights and user preferences.

## When to Pull Memory
- When a task touches user preferences, naming styles, or earlier decisions.
- When the user refers to instructions given in previous sessions.

## When to Save Memory
- When a durable architectural decision is made (e.g. stack choice, schema design).
- Persist concise conclusions with rationale. Avoid saving secrets or passwords.
