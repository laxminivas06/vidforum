# HOL Guard Skill

Verifies the safety and integrity of community plugins and external integrations.

## Audit Checks
- Check for obfuscated commands, unexpected network calls, or arbitrary shell invocations.
- Ensure plugins adhere to local-first and sandboxed execution boundaries.
