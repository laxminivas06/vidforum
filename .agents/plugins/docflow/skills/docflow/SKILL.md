# Docflow Skill

Documentation freshness enforcer.

## Policy
- Whenever an API route or schema is updated, ensure `docs/TECH_SPEC.md` and `docs/PRD.md` match.
- Check off completed items in `docs/TASKS.md` immediately upon verification.
- Never declare a milestone finished without updated documentation.
