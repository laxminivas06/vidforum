# Metabrain Skill

Evolves project observations into hypotheses and preferences.

## Workflow
1. **Observation:** Note repeated patterns in code style, error handling, or validation.
2. **Hypothesis:** When an observation recurs 3+ times, treat it as a working rule.
3. **Preference:** Once validated, graduate the hypothesis into an immutable project guideline in `.agents/rules/`.
