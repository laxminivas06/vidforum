# Knowl Project Memory Skill

Local-first factual memory that keeps project knowledge up-to-date and retires invalid facts.

## Procedures
- Link facts to specific files or code symbols.
- Whenever files are updated, review associated knowledge items and mark outdated facts as retired.
- Search knowledge items before designing new features.
