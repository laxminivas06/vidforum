# Spec-Driven Development Skill

Enforces rigorous specification before writing implementation code.

## Lifecycle Stages
1. **Requirements:** Define Problem, User Stories, and Acceptance Criteria in `PRD.md`.
2. **Design:** Define API contracts, data models, and component boundaries in `TECH_SPEC.md`.
3. **Tasks:** Break down work into small, sequential items in `TASKS.md`.
4. **Verification:** Validate output against acceptance criteria before closing tasks.
