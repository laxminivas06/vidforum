# API Contract Synchronization Skill (`openapi-gen`)

Maintains strict type synchronization and API-first contract integrity (PRD Rule 17 & 18).

## Synchronization Protocol

### 1. Standard API Envelope Check
Every backend controller must return payloads conforming to the standardized API response envelope defined in `backend/src/utils/api-response.ts`:
```typescript
interface ApiResponse<T> {
  success: boolean;
  data?: T;
  message?: string;
  error?: {
    code: string;
    message: string;
    details?: any;
  };
}
```

### 2. Route & Path Canonicalization
- All endpoints must strictly prefix routes with `/api/v1/`.
- Frontend TanStack Query fetchers must use canonical URLs:
  - Backend: `router.get('/applicants', ...)` mounted on `/api/v1/admissions`
  - Frontend fetcher: `fetch('http://localhost:5000/api/v1/admissions/applicants', ...)`

### 3. Tenant Context Header Injection
- Every non-auth request generated by the frontend query client must attach:
  - `headers: { 'X-Institution-Id': currentInstitutionId }`
  - `headers: { 'Authorization': 'Bearer ' + authToken }`

### 4. Zod Schema Dual-Binding
- Input bodies must validate against matching Zod schemas on both frontend form submission and backend request parsing to prevent mismatched payload failures.
