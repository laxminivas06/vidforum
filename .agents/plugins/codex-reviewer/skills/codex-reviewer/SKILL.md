# Codex Reviewer Skill

Performs fresh-eyes second-pass reviews to uncover hidden flaws before presenting code to the user.

## Checklist
- Did the implementation satisfy the exact requirements in `PRD.md`?
- Are any of the 30 Non-Negotiable Rules violated?
- Are responsive breakpoints (320px to 1440px) properly styled?
- Is error handling present for asynchronous operations?
