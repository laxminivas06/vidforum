# Dev Skills

Structured engineering methodologies.

## Core Workflows
- **TDD:** Write test first -> observe failure -> implement minimal code -> verify passing.
- **Root-Cause Debugging:** Formulate hypotheses, inspect logs/traces, verify fixes before refactoring.
