# Debt-Ops Skill

Eliminates silent AI technical debt by enforcing write-time accountability.

## Rules
- Never leave unresolved silent `TODO` or `FIXME` comments in code.
- If a feature is intentionally deferred to Phase 2/3/4, record it explicitly in `docs/TASKS.md` under the designated phase.
- Document any deliberate shortcuts in `docs/DECISIONS.md`.
